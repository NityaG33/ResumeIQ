Job Description

We are looking for a Frontend Software Engineer to build responsive, accessible, and user-friendly web applications. The ideal candidate should have strong knowledge of modern JavaScript development, React, web fundamentals, component-based architecture, and frontend performance.

Responsibilities

* Develop responsive and interactive web applications using React.js and modern JavaScript.
* Build reusable UI components and maintain scalable frontend architecture.
* Translate product requirements and design specifications into functional user interfaces.
* Manage application state and asynchronous data using appropriate React patterns and APIs.
* Integrate RESTful APIs and backend services into frontend applications.
* Implement client-side validation, error handling, loading states, and authentication flows.
* Optimize web applications for performance, responsiveness, accessibility, and cross-browser compatibility.
* Work with HTML5, CSS3, JavaScript, and modern frontend development practices.
* Use Git and GitHub for version control and collaborative development.
* Debug frontend issues and write maintainable, testable code.
* Collaborate with backend engineers, designers, and product teams to deliver complete web experiences.

Required Skills

* Strong proficiency in JavaScript and modern ES6+ features.
* React.js and component-based UI development.
* HTML5 and CSS3.
* Responsive web design.
* REST API integration and asynchronous programming.
* Understanding of browser fundamentals, HTTP, and client-server communication.
* Git and GitHub.
* Strong problem-solving and debugging skills.

Preferred Skills

* TypeScript.
* Tailwind CSS, Bootstrap, or similar CSS frameworks.
* React Router and state management libraries.
* Next.js or other modern React frameworks.
* Jest, React Testing Library, or frontend testing frameworks.
* Experience working with Node.js and Express.js.
* Understanding of web accessibility, SEO, and frontend performance optimization.

Education

Bachelor's degree in Computer Science, Information Technology, Software Engineering, or a related technical field.
